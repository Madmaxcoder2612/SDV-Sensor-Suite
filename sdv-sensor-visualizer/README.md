# 🚗 SDV Sensor Visualization Dashboard

An interactive web-based 3D visualization of Automotive Sensors used in modern Software Defined Vehicles (SDVs).

## ✨ Features

- 🌌 3D vehicle visualization (Three.js)

- 🎯 Interactive sensors (hover + click)

- 🧠 Real-world sensor data (LiDAR, Radar, Camera, etc.)

- 🖼️ Sensor images in detail panel

- 🌙 Dark mode UI with glassmorphism

- ⚡ Lightweight (Vanilla JS, no frameworks)

---

## 🧪 Sensors Included

- LiDAR (Velodyne)

- Radar (Continental)

- Camera (Bosch)

- Ultrasonic Sensors

- IMU (Inertial sensors)
